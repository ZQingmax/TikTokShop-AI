## 真实调用与限制

真实样本为采集箱中的 1688 商品 1090443573903（带盖编织收纳筐）；授权目标店铺为马来西亚 Mivello Finds。

- qwen3.5-plus 图片文字识别成功，request_id 保存在任务和证据中。
- qwen3.5-plus 文案调用成功，但初次候选夹杂中文及非消费者说明；后续加入全英文检查与更严格提示词。历史不合格候选不能直接采纳，语言检查失败也不会修改草稿。
- qwen-mt-image-2.0 翻译任务成功；复用原结果修复本机 Fake-IP 下载后，完成本地副本和妙手图片空间转存，没有重复调用翻译模型。
- 旧域名图片兼容接口返回 404。已按用户提供的业务空间 ID 配置独立图片地址；空间下的生图测试在用户要求减少付费测试后停止，结果不确定，不自动重试。改图未在新地址继续真实调用。
- 实际商品缺少包装长宽高及经确认的店铺售价、库存，未填造这些值，未执行真实妙手商品保存。采集至店铺保存及回读的流程已用明确标注的夹具完整验证。

按用户要求，停止新增付费测试。真实测试脚本默认只执行一次 OCR，并以 --max-model-calls=1 限制调用预算；后续验证主要使用本地夹具。
